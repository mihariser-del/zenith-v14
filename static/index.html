Frequently asked questions

Is Zelpophai AI free to use?

Yes. You can start chatting for free, even without an account. Paid plans unlock higher limits and extra features like video generation.

Can Zelpophai AI really create documents, images and videos?

Yes. Ask it to write a report, resume, presentation or spreadsheet and it produces a downloadable file. Ask for a picture and it generates an image you can refine. Pro members can turn a sentence or a photo into a short video with sound.

Does it remember previous conversations?

With an account, your chats are saved and the assistant can use that context later, so you can pick up where you left off. Guest chats stay on your device.

Can I use it to write and run code?

Yes. The Coding AGT. page provides a code editor with syntax highlighting and a runner for JavaScript and HTML, plus a server-side runner for other languages.
